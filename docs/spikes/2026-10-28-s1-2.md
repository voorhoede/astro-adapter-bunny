# S1 step 2: builtins, WebAssembly and script size on bunny.net

Run on 2026-10-28 against one throwaway standalone script and its pull zone, deleted afterwards. Runtime: Deno 2.7.12, V8 14.7.173.20. The sources are in [`2026-10-28-s1-2/`](2026-10-28-s1-2/): `gen.mjs` writes one script variant, and `run.sh` deploys it, waits until the new version answers, then makes five requests with fresh query strings, measured from the Netherlands.

## Builtins and WebAssembly

Each variant imports one builtin statically, since `import()` fails on bunny.net (S1.1). Each also carries Shiki's WebAssembly engine (466,610 bytes) and compiles it per request.

| Variant | Result |
| --- | --- |
| `node:path`, `node:buffer`, `node:crypto` | Starts and serves 200, in 0.16 to 0.30 s |
| `node:child_process` | Never starts: every request answers 400 with an empty body |
| `node:vm` | Never starts: 400 with an empty body |
| `node:worker_threads` | Never starts: 400 with an empty body |

- WebAssembly works: `WebAssembly.validate` and `instantiate` on a minimal module, and `WebAssembly.compile` of Shiki's engine in 2.2 ms.
- The publish is accepted for every variant. A broken builtin shows only at the first request, so the build has to catch it.
- The script recovered on the next publish after each broken variant.

## Script size

Generated code, not strings: small functions that the engine has to parse, up to the target size.

| Script | Status | Time to first byte, 5 requests |
| --- | --- | --- |
| 1.0 MB | 200 | 0.17 to 0.31 s |
| 3.0 MB | 200 | 0.58 to 0.67 s |
| 5.0 MB | 200 | 0.86 to 1.01 s, and one warm request at 0.12 s |
| 7.0 MB (7,340,390 bytes) | 200 | 1.16 to 1.30 s, and one at 3.74 s |
| 9.0 MB (9,437,534 bytes) | none | Every request timed out after 30 s; the publish was accepted |

- Nearly every request started a cold isolate. Startup grows with size, at about 0.15 to 0.2 s per MB from here.
- The limit lies between 7.3 and 9.4 MB. Not measured: where in between, and how far real Astro code differs from generated functions.

## What it decides

- The three builtins `build/bundle` refuses are the three that break startup. Others were not tried one by one.
- The eager script limits in ADR 0007 hold: fail above 7 MB, which still started; warn above 1 MB, where a cold request already costs about 0.2 to 0.3 s.
